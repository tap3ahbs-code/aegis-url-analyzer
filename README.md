# Aegis — локальная проверка URL

Интерактивный веб-сервис для оценки признаков риска в URL-адресе. Работает локально, без учётных записей, API-ключей и сторонних Python-библиотек.

## Запуск

Нужен Python 3.9 или новее.

- Windows: дважды щёлкните `start.bat`.
- Другие системы: выполните `python server.py`.
- Страница откроется автоматически: <http://127.0.0.1:8765>.
- Для остановки нажмите `Ctrl+C` в окне сервера.

## Что делает версия MVP

Анализирует текст URL: схему, домен, длину, необычные символы, параметры перехода и другие признаки. Также проверяет **точное совпадение URL** с локальным снимком проверенных фишинговых адресов [PhishTank](https://phishtank.org/developer_info.php). Выдаёт объяснимый индекс от 0 до 100. Это **не вероятность вредоносности**, и низкий индекс не означает, что сайт безопасен. Сервис не открывает проверяемый адрес.

База хранит только SHA-256-хеши адресов, а не сами ссылки. В ней 46 042 записи на момент подготовки этой версии; актуальное число и дата снимка отображаются в интерфейсе. Чтобы обновить базу, запустите `update_threats.bat` (на других системах — `python update_threats.py`). Для обновления нужен интернет; проверка уже загруженной базы работает без него. Бесплатная загрузка без ключа может ограничиваться источником по частоте.

Все запросы обрабатываются на `127.0.0.1`. В `localStorage` браузера сохраняются только домен и оценка, без полного URL; в консоль сервера URL не записываются. Изображаемые на странице тестовые ссылки синтетические и предназначены для демонстрации признаков.

## Структура

- `server.py` — локальный HTTP-сервер и API `POST /api/analyze`.
- `analyzer.py` — правила анализа URL.
- `threat_db.py`, `update_threats.py`, `data/threats.sqlite3` — локальная база и обновление.
- `web/` — интерфейс сайта.
- `tests/` — проверка ключевых случаев.

## Оформление

Светлая песочная палитра и лаконичная типографика дополнены пальмой и листьями на прозрачном фоне. В поддерживаемых браузерах листья плавно отклоняются по ходу прокрутки средствами CSS; при системной настройке уменьшения движения анимация отключается. Внизу страницы песчаная кромка переходит в океан. Изображения находятся в `web/palm-hero.png` и `web/palm-frond.png`. Шрифт Manrope сохранён локально из открытого каталога Google Fonts; лицензия OFL находится в `web/fonts/`.

Проверка анализатора: `python -m unittest discover -s tests -v`.
